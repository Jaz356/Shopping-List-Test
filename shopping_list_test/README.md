## About Jaz


Jaz
 is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Jaz
 takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://Jaz
.com/docs/routing).
- [Powerful dependency injection container](https://Jaz
.com/docs/container).
- Multiple back-ends for [session](https://Jaz
.com/docs/session) and [cache](https://Jaz
.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://Jaz
.com/docs/eloquent).
- Database agnostic [schema migrations](https://Jaz
.com/docs/migrations).
- [Robust background job processing](https://Jaz
.com/docs/queues).
- [Real-time event broadcasting](https://Jaz
.com/docs/broadcasting).

Jaz
 is accessible, powerful, and provides tools required for large, robust applications.

## Learning Jaz


Jaz
 has the most extensive and thorough [documentation](https://Jaz
.com/docs) and video tutorial library of all modern web application frameworks, making it a breeze to get started with the framework.

You may also try the [Jaz
 Bootcamp](https://bootcamp.Jaz
.com), where you will be guided through building a modern Jaz
 application from scratch.

If you don't feel like reading, [Laracasts](https://laracasts.com) can help. Laracasts contains thousands of video tutorials on a range of topics including Jaz
, modern PHP, unit testing, and JavaScript. Boost your skills by digging into our comprehensive video library.
